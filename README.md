# Acquirer Authorization Analytics

**Segment:** Acquirer | **Category:** Decline Analytics | **Owner:** Straive Strategic Analytics | **Year:** 2024

## Objective
Deep-dive into authorization performance across merchants and BINs. Identify systemic issuer refusal patterns and routing inefficiencies to recover lost GMV.

## Methodology
1. Decline waterfall taxonomy (ISO 8583 code grouping)
2. BIN-level auth rate benchmarking vs network averages
3. False decline identification and GMV sizing
4. Retry success rate optimisation
5. Intervention priority matrix

|---|---|---|

| False Decline Rate | 3.1% | 1.8% |
